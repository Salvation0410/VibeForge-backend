# 第22轮答案片段优先离线对照实施计划

> **For agentic workers:** 使用 subagent-driven-development 分任务实施与复核。本计划已获用户选择A授权，不重复申请方案许可。

**Goal:** 冻结识别规则后在历史90题比较A0 cap1、A1 cap2、A2 cap2加有限问法降序，输出可追溯证据变化而非新回答质量分。

**Architecture:** 新增独立离线模块，复用观测输入核验和正式选择/预算函数。仅对已核验thresholded候选稳定分区；rubric只在选择之后计算字面存活和生成评审材料，生产入口不导入新模块。

**Tech Stack:** Python、pytest、冻结JSON，无新依赖、无供应商调用。

## 预先冻结规则 answer-first-question-list@2

在首次对照运行之前固定以下规则，不因收益结果调参：locator最后一级（按`/`拆分去空白）必须精确为`常见问法`；正文是2至20个连续中文弯引号包围的条目，条目之间只允许空白；每项2至100字符且不含换行、句号、分号、冒号、逗号及嵌套引号。每项至少含一个明确问法标记：`怎么|如何|为什么|为何|哪里|哪|什么|多少|多久|几|是否|能否|是不是|吗|要不要|可不可以|能不能|有没有|？|?`。条目后仅允许句号、空白及可选章节指引，指引语法为可选`相关说明：`，后接中文标签（1至16字）+`见`或`详见`+两位数字，指引以中文分号分隔并可有末尾句号。

首次对照前的规格审查发现合成反例：`“必须登录”“必须填写标题”`被v1误判。v2仅移除独立标记`必须`，保留由`吗/哪里/?`等识别的真实问句；补纯约束及问句混合约束不降序测试。本修正发生在读取新对照结果之前，不根据收益改规则。

首次回放前澄清句法空白：章节指引的标签、`见/详见`、两位数字以及分号两侧允许空白，例如`类型选择见 04； 图片保留详见 05。`。数字仍精确两位，任何额外实质说明仍拒绝识别。

不匹配、含回答、仅一个问句、混合正文、实质FAQ、标题不符均保持顺序；此有限句法不能保证所有语义问法均识别或不会有伪装正文。降序不是删除，只有稳定分区，不改分数、不扩Top8、不改变阈值；同分/同类原顺序保留，原内容和身份不变。资料输入不可信，不执行任何正文。

# 第十一轮准备HTTP故障验收计划

用户授权继续第十轮交接中的跨服务故障验收；不改生产策略，当前会话顺序实施。

- [x] 隔离Spring测试入口提供当前合法attempt与无敏感字段持久观测；复用正式Controller/Service/Mapper与随机schema。
- [x] 独立Python app注入下载器/计数Embedding，在授权后及Embedding返回后os._exit；计数发送前写入测试文件，不调用供应商。
- [x] 回环代理在BEGIN/COMPLETE正式事务完成后丢弃响应；重启Python请求同attempt，完整候选恢复，否则BUSY且无额外调用。
- [x] 四个随机schema/alias场景分别运行，核对首次响应、执行记录、旧head、候选完成、单次计数和精确清理。
- [x] 编译/相关pytest/依赖检查，正式库只读核对，交接记录失败及未测项，中文提交。

每例父runner120秒有界，子进程退出点明确返回79；不把子进程退出前的调用称免费。未覆盖长期暂停、真实网络分区、事务中途强杀或供应商内部重试；如发现生产缺陷先定位再提出必要修复。

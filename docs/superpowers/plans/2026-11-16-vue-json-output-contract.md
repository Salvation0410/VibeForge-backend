# Vue 首轮 JSON 输出提示修正计划

> **For agentic workers:** 使用 executing-plans 在本会话顺序执行，不派生代理。

**Goal:** 按用户确认的 A 方案，将格式重试时才显式提供的单个JSON输出要求提前到Vue共用系统提示，减少对象外说明引起的无效轮次。

**Architecture:** 只修改 generation.py 的 Vue 提示。generate 与 repair 已共用该提示，首次生成、已有页面增量和修复均覆盖；解析、工具校验、重试和共享预算不变。非法响应继续整轮丢弃，不提取说明后的JSON。

**Tech Stack:** Python、pytest、LangChain供应商适配器、原累计验收账本代理。

## 证据与设计

第39轮两个首轮响应均为210字符，20字符的对象外说明后是完整JSON，两者SHA-256相同；STOP正常结束。离线复现原响应拒绝、仅对诊断副本去除说明后两个读取工具被识别。18份Vue响应中其余16份接受。源码当前只在vueFormatFeedback显式禁止对象外说明；共用初始提示仅要求工具调用严格JSON，没有明确限定整轮响应。

选A：在工具协议首部增加每轮单对象要求，说明放content，禁止对象外前言、总结、多段JSON与Markdown围栏。已有解析器对完整围栏的兼容不变，提示约束不能写成接受范围收紧。用户已比较并拒绝B（尝试提取说明中的JSON），不改变解析器。

## 交付限制

不增加模型格式重试次数、40次工具预算或两次修复上限；不默认启用JSON response_format，不吞取消，不执行非法响应中的合法子片段。真实诊断可能仍不遵循提示，失败也保留且不重试。单轮真实响应不是模型必然收敛的证明。

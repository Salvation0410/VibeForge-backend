# 单文档配额离线证据验证计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans；逐事实语义复核使用独立代理，最终结果仍为代理审阅、人工待办。

**Goal:** 基于已冻结的重排开启组候选，验证 cap2 相对 cap1 的证据收益及跨文档损失，不把证据覆盖当成答案通过率。

**Architecture:** 只读取 `tmp/rag-verification-20261118/live/` 的实际 Top8、BGE 顺序、语料、映射和查询向量。复用既有实验选择器及正式字符/字节预算，保持最多三块、1200 字符/块、3000 字符总量、16384 字节 JSON 预算。cap1 必须完整复现原 90 个开启组最终上下文，cap2 只改变单文档配额。分析脚本和正文证据留在忽略目录；仓库仅提交方法、脱敏聚合及交接。

**Tech Stack:** Python 3.12、既有只读选择/预算函数、JSON 指纹、独立代理语义审阅。

## 预先固定的范围与判据

- 90 题全部回放；81 道可答题的 130 项公共必要事实逐项判断，9 道拒答题只检查回放和预算，不产生新拒答准确率。
- 维持原 draft-2；支付口径是后置独立澄清，不修改冻结标注或原答案，本轮不发布新语料。
- 每项事实分为 `covered/partial/missing/contradicted/ambiguous`。`covered` 要求最终上下文支持必要事实全部要素、对象与适用条件，必须给出真实片段的逐字证据；整段标注引文命中只作机械诊断。
- 匿名化 cap 标签及组内顺序，不提供旧答案、旧评分、Top8 未入选正文或私有配额映射。预读 rubric 核对冻结身份，事实字段不参与选择，完成选择后才投影审阅事实；三份独立复核覆盖全部必要事实及两组最终文本。
- 比较事实覆盖转移、完整证据题数、增加/丢失的块与文档、字符/字节裁剪、原 quota 遗漏的恢复数量；证据缺失不直接改写历史生成归因。
- 所有输入和旧授权账本前后核对指纹，拒绝联网。新聊天/Embedding/BGE 推理/INDEX/生产写入均为零。

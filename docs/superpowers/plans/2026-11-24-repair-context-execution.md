# Vue 修复上下文与工作集实施计划

> **For agentic workers:** 使用 executing-plans 在当前会话逐项执行；用户已确认调查文档推荐的两步范围。

**Goal:** 区分可见无效重读与省略补读，按有界问题工作集执行 Vue 修复。

**Architecture:** 适配器从最终投影产生请求内私有可见性元数据，经 ModelTurn 返回 Vue 子图。子图按读取前可见内容的指纹计数，保持完整审计历史与共享预算。严格问题反馈及 Spring 快照清单组成修复任务，模型提出最多三文件工作集，平台验证后限定操作及投影；结束仍走原验证。

**Tech Stack:** Python、LangGraph、pytest；沿用 Spring 内部网关。

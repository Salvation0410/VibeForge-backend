# 同名书籍筛选删除验收：方案 A

用户已选择保留重名、增强目标身份验收。新增独立固定探针，不修改生成平台或产品策略，不放宽原书名唯一探针。当前成功隔离样本478668026865614848允许重名并按独立ID操作，先用零模型浏览器验收这份原产物。

探针要求三本原始未读书及3/0计数，先添加同名测试书并标已读，再添加第二本同名未读书。每次定位从准确书名叶节点向上有界寻找仅含一个状态按钮和一个删除按钮的最小卡片，以书名和状态共同筛选且要求唯一；歧义失败，不任取第一张，不读取Vue内部实例或源码ID。已读筛选删除第一本，核对同名未读仍在且原书不变；再将剩余同名标已读、添加新同名未读，在未读筛选删除后保留已读同名，最终删除同名已读恢复3/0。

手写浏览器夹具分别模拟按ID合法删除、按标题删全部、按筛选索引误删、按标题删第一条、已读计数滞留及重复卡片歧义。验证探针拒绝错误，不将手写夹具称为自然模型结果。原列表/删除探针同步回归。

探针会改变隔离页面内存，不用于用户正在使用的页面，不要求刷新持久化，不覆盖两个同名且同状态的任意身份区分。只通过正常静态预览读取原构建产物，独立profile隔离存储，模型账本不变；若真失败先记录原因，不手改产物。文档同步交接后精确提交，不推送。

# 第27轮：固定语料混合检索对照

用户明确要求“直接加入混合检索对照看是否引入混合检索后效果会提升”。沿用当前开发分支和历史实验设施，新增独立实验；这授权本轮比较，不代表生产启用。

## 固定范围与取舍

采用第23轮问答关联63块语料、同90题、cap1、最终最多3块、单块1200/总3000字符、提示16384字节。第26轮58块答案单元暂不混入，避免语料与检索同时变化。比较两组：

- dense：复用第23轮真实向量，f32穷举COSINE Top8，新运行BGE。
- hybrid：相同dense Top8与BM25 Top8按等权RRF融合，取Top8，新运行相同BGE。

BM25使用中文连续段相邻双字词元（单字段保留单字）、ASCII字母数字下划线单词、小写、NFKC；无词典、停用词或查询扩写。k1=1.2、b=0.75，IDF=log(1+(N-df+0.5)/(df+0.5))，查询词去重。只保留正分。RRF=sum(1/(60+rank))，排名从1开始；缺路贡献0；同分按原语料序号确定。融合后保留8条以保持BGE候选预算一致，可能挤掉仅dense命中的必要事实。只考察这一预注册变体，不证明所有混合检索策略。

不选分数线性相加（两路分数尺度不同）；本轮不选最多16条并集重排（改变BGE预算）；不按90题结果调分词、权重、深度或语料。BM25 Top8与合并前并集作为定位诊断，不另跑模型。

## 执行与输入完整性

先核对第23轮计划、账本、报告摘要及原绑定，重建63块；复算所有90题dense Top8和分数与历史一致。向量文件大小约19MiB，独立有界读取并冻结hash；核对63/90行、3072维、有限非零值、原Embedding各批输入摘要。向量没有供应商签名，历史批次绑定及Top8重现只是本地完整性证据。

新固定锚点tmp/rag-hybrid-20261120/authorization.jsonl；最多180次本地真实BGE（90×2），Embedding/Chat/INDEX/生产写入0。每次推理前预占flush/fsync，失败/取消占额度；首错停止，无重试/续跑/更换输出绕过。真实模式显式--live和计划hash；默认prepare不推理。固定缓存BGE修订、单并发、交替组顺序；无模型下载，无服务启动要求，非Milvus或双服务端到端验收。

运行前源码复核发现正式适配器遇CUDA OOM会缩批重试。本轮独立worker保留正式模型加载、GPU锁、IPC和清理，只把评分适配换为同一底层评分函数的单次调用；每批最多4对，180次重排最多360个固定批次，失败不补批、不重试。两组相同路径，旧基线差异单独核对；不修改正式服务的适配器。

# Vue 必填属性的有限确定性检查

承接交接第 17 节。浏览器无异常或构建成功都不能证明筛选接线正确；生产 Vue 的缺失属性警告可能被移除。本轮先在 Spring Vue 构建成功且 dist 存在之后，增加官方 Vue SFC AST 驱动的本地组件必填属性检查。

检查器作为可信 CJS 资源随服务发布，通过现有可取消、限时、输出有界的 CommandRunner 执行。仅加载项目已安装的 Vue compiler，不执行或导入应用组件。只分析 script setup 中直接声明的运行时 defineProps/defineModel、静态相对 .vue 默认导入，以及模板中静态可解析的属性、v-bind:name 和 v-model。缺少显式 required:true 属性时返回最多四条路径/组件/属性证据，不返回源码。必填项带 default、类型声明、宏参数/键无法确定、对象展开、动态绑定、普通 Options API、onX 事件属性声明等情况跳过（事件监听器可提供这类属性，当前不模拟转换）。检查通过仅表示受支持范围内未发现该类问题。

最多遍历 20000 项，最多选择 24 个 Vue 文件，单文件最多 12000 字符/读取 48000 字节、合计 60000 字符；不跟符号链接，剪枝依赖/构建和隐藏路径，超界文件跳过并记录计数。只比较实际读到的完整父子文件，缺失或不支持的文件不能视为没有 props。没有源码修改，不执行用户函数来计算 props，也不新增模型调用。

命令使用 Node 直接参数，资源放服务创建的临时文件，用完清理；返回 JSON 做协议检查。确定缺失返回 built=false/VUE_COMPONENT_CONTRACT_FAILED，通过既有 project_build 结果进入有限修复。检查器缺失、超时或输出损坏返回 VUE_COMPONENT_CHECK_UNAVAILABLE，Python 直接终止，不花模型调用修复环境。首次生成和修复的强制构建执行检查，已有 dist 的 ensure 快路径不重新检查。取消继承现有进程树清理与请求所有者规则；15 秒是命令等待限时，进程/输出收尾仍有原额外限时。

没有新增工具或跨服务字段，错误码属于现有字符串；不使用正则解析 Vue。未实现事件语义、模板全部变量解析、动态/跨文件类型系统或浏览器交互验收。编译器不可用会失败关闭；这需要支持的 Vue 工程安装标准 Vue compiler。合法但不支持的语法记录跳过，不伪装成全工程已验证。

验收：旧构建成功时新增回归应失败；Node 测试覆盖缺失 props、正确显式/具名模型、kebab-case、动态/展开/类型/截断/符号链接和边界；Java 覆盖构建门禁、协议损坏及取消；Python 注入新错误结果验证有限修复与终止。对第 16 节历史快照零模型检查，仅保留派生摘要，不写工程。必要真实模型验证沿用累计124账本；不为本轮确定性检查默认重新生成。

# 预览更新加载图正圆修复设计

## 背景

预览更新提示使用横向 Flex 布局。加载图虽然设置了相同的宽度和高度，但作为 Flex 子项仍允许收缩；提示文字较长或可用宽度不足时，加载图宽度会被压缩，最终显示成椭圆。

## 目标

- 保留现有 30px 双环加载图、配色和旋转动画。
- 在长文案和窄屏布局中始终保持正圆。
- 不改变提示框尺寸、提示文字或其他预览状态。

## 方案

在 `AppChatView.vue` 的通用 `.preview-spinner` 样式中禁止 Flex 压缩，并声明固定的 1:1 比例：

```css
.preview-spinner {
  flex: 0 0 auto;
  aspect-ratio: 1;
}
```

现有 `.preview-spinner--small` 继续提供 `30px` 宽高。通用加载图位于非 Flex 布局时，上述属性不会改变现有尺寸；位于预览提示框时，不再被右侧文字挤窄。

## 验证

1. 前端类型检查和生产构建通过。
2. 桌面端预览更新提示中的加载图宽高一致。
3. 缩窄页面后加载图仍保持正圆，文字正常换行。
4. 加载图动画、颜色和提示框布局不发生其他变化。

## 非目标

- 不替换加载动画。
- 不调整加载图尺寸、颜色或速度。
- 不修改预览提示文案。

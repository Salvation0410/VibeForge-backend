# Vue 增量删除功能验收

用户要求按交接第 26 节继续。本轮限定为一个新的隔离应用先自然生成固定读书清单，再用新的普通用户请求追加删除书籍功能，不修改历史验收应用。原探针验证基线和增量后的原功能，新独立删除探针验证状态一致性，不接入生产流程。

删除需求限定每本书有“删除书籍”按钮，点击直接删除，无确认框；保持原三种筛选、计数、添加和切换。删除探针先调用原探针得到四本未读书，再标记小王子已读，在已读筛选删除小王子；切未读后删除人类简史，切全部确认删除持久于当前页面全局状态，逐项核对剩余书名/计数。继续删空、添加一本书并切换已读，验证空列表可恢复。这里不要求刷新持久化。

定位从唯一书名文本对应的有限祖先容器寻找一个状态按钮和一个删除按钮；歧义直接失败，不任取按钮。结果只保存固定步骤与计数，不输出 DOM 或源码。手写夹具分别模拟合法实现、仅修改筛选视图、删除后已读数未更新、删除错误书籍，先证明探针能拒绝错误。

真实模型沿用原账本，起点 209；失败和重试均计入。用独立 Spring/Python/代理端口，预检后启动，收尾只关闭本轮拥有的服务。没有自然修复就如实记未触发，真实失败先保留证据；多个生产修复方案需要用户确认。

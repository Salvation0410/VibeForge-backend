# 生成界面异步竞态隔离

承接交接第 10 节。复用真实 Vue/Chrome 与合成 API/EventSource 的浏览器夹具，通过可释放响应门闩验证停止失败、跨应用导航和新轮次开始后的迟到响应；本轮不调用模型。

每次详情、历史、预览请求记录页面和生成轮次，响应、异常和 finally 写入前核对归属；同类并发请求以最新请求为准。终态异步回源的各 await 之间也核对，禁止旧回调借当前 appId 发新请求。停止响应/轮询核对 stopId 并使用原 appId。

停止等待期间保存已到达的流终态。取消被接受则丢弃缓存，按停止状态确认；取消失败则消费缓存或继续原流，避免流已关闭但界面永久 running。用户已点停止的本轮保持预览不自动刷新，后续新轮次成功仍可正常刷新。

保留既有 SSE、后台取消、模型预算、2000 字符/80ms 展示与客服修改。采用局部请求归属检查而非重建整个状态管理；仅取消 fetch 不能保证已返回响应及业务回调失效，不能替代归属验证。测试范围与真实后端验收明确区分。

# 生成产物交付与页面归属

交接第 15 节已覆盖生成取消收尾，下一步检查生成后的下载与部署，并补充 Vue 从零生成的真实证据。

当前页面的部署、源码下载和对话导出回调直接写响应时的页面状态；切换应用后，旧响应可能覆盖部署链接、触发旧文件下载或清除新请求的 loading。先用真实 Vue 组件和合成 HTTP 门闩复现，再作小范围修复。

每项操作固定发起时的 appId、文件名和页面代次；成功、错误提示、异步 Blob 错误解码及 finally 均核对页面归属。页面导航和卸载使旧响应失效，同一页面开始新一轮生成不使已有交付请求失效。仅抑制失效页面的 UI 副作用，不承诺取消服务端部署或撤销已发生的文件操作。无需新增接口、改变生成协议或扩大为全站请求管理。

测试包含导航后成功/失败、导航后又发起同类操作、组件卸载、同页新一轮生成及 Blob 解码期间导航。采用页面级归属检查；不采用取消 HTTP 作为唯一保障，因为服务端操作可能已开始，取消不能替代响应归属判断。

真实验收使用新建隔离 Vue 应用，经正常创建/生成入口调用真实模型；复用原无上限账本，发送前保留唯一提交标记。完成后通过真实前端检查功能，下载源码并核对压缩包，再调用本机部署入口检查页面。所有私有日志、源码和截图仅保存在 ignored tmp/doc，不提交；部署只在本机地址访问，不将 OSS 截图或本机部署称为公网发布验收。未触发的自然修复分支仍标记未覆盖。

## 实测发现后的范围补充

第二个真实 Vue 样本的 Markdown 导出包含 node_modules 和 dist，达到 19.7 MB。将导出目录遍历改为入口剪枝，与源码 ZIP 的目录排除范围一致，保留源码、锁文件、文档与排序，不跟随符号链接。先用三种生成类型的隔离目录测试复现，再以原应用零模型导出复验；不修改生成产物。

相同需求中的“不需要登录、远程后端或外部图片”未被旧规则识别，额外配图引发后续工具轮次。扩展同分句内、有长度和修饰词约束的并列否定识别，排除保护旧图动作；保留后句明确新增的优先级，不扩大工具预算。用一个新隔离应用做真实对照，不重复生成已有提交。

第三个样本确认模型上下文配图资源为空，但浏览器发现生成的筛选组件缺少数据，Reviewer 仍 PASS。该功能失败作为后续 Vue 运行期/功能审查缺口保留，不能因模型调用减少而计为完整验收通过，也不以手改生成源码代替自然生成结果。

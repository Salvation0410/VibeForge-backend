# 有限长度流式输出与简短优化提示设计

## 背景

当前前端已经避免把模型返回的完整源码逐分片写入 Vue 响应式状态，因此解决了大段 HTML 反复复制和渲染导致的页面无响应问题。但当前界面只显示字符数进度，缺少用户期望的实时内容反馈。

同时，现有“优化提示”包含“信息层级”“响应式表现”“输出协议”等偏专业表达，普通用户不容易快速理解。

## 目标

1. 生成期间继续实时展示模型输出内容。
2. 可见内容长度保持固定上限，不能重新引入完整源码持续渲染问题。
3. 生成完成后仍以服务端聊天记录为最终内容。
4. HTML、多文件和 Vue 三类优化提示改为简短、直接、普通用户可理解的表达。
5. 保留图片保护、完整产物和禁止额外说明等安全要求。

## 流式内容窗口

扩展现有 `generationStreamProgress`，在非响应式累加器中保存：

- 已接收总字符数。
- 最近 2000 个字符。
- 已用时间。

分片到达时只修改普通 JavaScript 状态。每 80ms 最多向 Vue 提交一次快照，避免每个 token 都触发组件更新。

聊天中的临时 AI 消息显示：

```text
正在生成，已接收 12345 个字符

……最近 2000 个字符……
```

超过 2000 个字符时只移除显示窗口中的旧内容，不影响后端接收、保存和发布完整结果。生成完成后重新加载聊天记录，用服务端最终消息替换临时窗口。

停止、失败、取消和组件卸载必须取消待执行刷新，并拒绝迟到分片继续更新页面。

## 简短优化提示

三类提示都使用普通用户语言，并共享以下要求：

```text
保留原有功能、文字、图片和操作方式。不要删除或替换原有图片，也不要添加无关内容。
```

HTML：

```text
请让当前页面更美观、更清晰，并适合电脑和手机使用。保留原有功能、文字、图片和操作方式。不要删除或替换原有图片，也不要添加无关内容。请只返回一个完整可运行的 HTML 文件，不要附带解释；如果无法完整生成，请不要输出残缺代码。
```

MULTI_FILE：

```text
请让当前页面更美观、更清晰，并适合电脑和手机使用。保留原有功能、文字、图片和操作方式。不要删除或替换原有图片，也不要添加无关内容。请完整返回 index.html、style.css 和 script.js，不要附带解释；如果无法完整生成，请不要输出残缺代码。
```

VUE_PROJECT 及未知类型：

```text
请让当前页面更美观、更清晰，并适合电脑和手机使用。保留原有功能、文字、图片和操作方式。不要删除或替换原有图片，也不要添加无关内容。只修改完成这次优化需要的文件，不要重建项目或添加无关功能，并确保修改后可以正常运行。请完整完成所有修改，不要附带解释；如果无法完整生成，请不要输出残缺内容。
```

## 组件边界

- `src/utils/generationStreamProgress.ts`：维护有界字符窗口、累计字符数和刷新节奏，不依赖 Vue。
- `src/pages/AppChatView.vue`：把快照显示到临时 AI 消息，处理完成、失败、停止和卸载。
- `src/utils/optimizePrompt.ts`：只负责按生成类型返回简短提示。
- 对应 Node 测试验证窗口不会超过 2000 字符、总字符数准确、最终刷新和销毁语义正确。

## 验证

1. 输入 10,000 个分片时，80ms 窗口内仍只安排一次刷新。
2. 累计字符数等于所有分片总长度。
3. 可见内容永远不超过 2000 个字符，并且是输出末尾内容。
4. `finish()` 同步提交最终窗口；`dispose()` 后不再回调。
5. 三类提示不包含“信息层级”“响应式表现”“技术栈”“输出协议”等不必要术语。
6. 三类提示仍明确保留图片、禁止残缺结果，并保留各生成类型必要的文件要求。
7. 运行前端单元测试、类型检查和生产构建。

## 非目标

- 不在浏览器中保存完整生成源码副本。
- 不引入代码编辑器或虚拟列表组件。
- 不改变后端 SSE 数据格式。
- 不触发事故应用的新一轮生成。

# 生成界面失败与停止验收

承接结构化编辑交接文档第 9.4 节，优先完成真实 Vue 界面的故障注入。本轮在已有继续优化授权内直接执行；使用已安装 Chrome headless 和 Vite，不增加依赖或真实模型调用。

在隔离 Vite 服务挂载生产 `AppChatView`、Pinia、Router 和 Ant Design Vue。业务 HTTP、预览文件与 EventSource 使用测试夹具，禁止代理至 Spring；通过 DOM 输入和按钮点击操作真实组件。覆盖三类生成的三个质量失败码，以及停止返回 IDLE、STOPPING、COMMITTING 后归于 IDLE。断言中文错误、请求 ID、旧 iframe/document 和本地交互状态保留、无额外预览请求、迟到事件无效；同时验证失败后新一轮成功仍只刷新一次。

源码显示停止返回 IDLE 和 COMMITTING 后结束都直接刷新预览，需先用浏览器复现。IDLE 仅表示执行结束，COMMITTING 不证明发布成功；停止流程应保留预览并允许用户显式刷新。修复不得改变 SSE、后台取消、生成预算、流式窗口及用户客服修改。

只做纯函数测试不能覆盖组件实际接线；启用真实模型无法稳定制造所需失败及竞态。因此采用真实浏览器组件加故障夹具，并明确不是 Spring/模型端到端验收。先记录失败，再修复与重跑，更新交接并分别提交仓库。

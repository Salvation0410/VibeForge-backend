3. 生成中观察原生 SSE 和旧 iframe，记录账本。成功场景等待真实终态；取消场景在输入审核后的生成调用已预占时点击“停止生成”，等任务确认，不能仅凭 STOPPING 判定成功。
4. 成功核对新预览目标属性及其他保持项、一次刷新、计数功能。失败/取消核对零刷新和原 document/计数；静态产物通过 Spring `artifact_context` 比较，Vue通过 `vue_source_snapshot` 报告实际变化。
5. 将唯一终态与显式任务查询、供应商审查证据和预算交叉核对。保存截图并人工查看布局与图片，记录未覆盖项。

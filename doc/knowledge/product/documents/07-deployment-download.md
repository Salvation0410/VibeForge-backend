# 部署、访问与代码下载【当前功能】

## 部署前提与步骤【当前功能】

使用创建应用的账号登录，进入该应用对话页，先确认已有可用生成结果并验收页面，然后点击“部署应用”。部署成功后得到访问链接，可以打开新标签页验证。后端部署操作只允许应用创建者；管理员能管理应用不意味着可以直接部署别人创建的应用。没有源码目录或 Vue 构建产物时部署可能失败。

## 部署与预览区别【当前功能】

预览用于查看当前生成结果，部署将源码或构建产物复制为可访问站点。后续生成成功不会自动替你重新部署；修改后想让部署链接显示新内容，应再次点击“部署应用”。已有应用部署会复用其部署标识，更新同一发布位置；不能承诺每次部署都生成全新链接或保留部署历史回滚入口。

## 三类产物【当前功能】

HTML 和 MULTI_FILE 部署读取可用源码版本；Vue 工程部署使用可用的构建产物。源码 ZIP 与线上站点文件不是同一个用途。页面原型发布不等于平台替生成应用开通真实支付、用户账户或数据库，需要单独验证后端服务与外部接口。

## 下载代码【当前功能】

在应用对话页点击“下载代码”，浏览器下载源码 ZIP。下载接口要求登录且只能由创建者下载；管理员管理权限不能推导为下载他人源码或部署他人应用的权限。聊天 Markdown 导出允许创建者或管理员，但与源码下载权限不同。压缩包排除 node_modules、dist、build、.git、.env、日志和临时文件。Vue 下载后需在本地安装依赖并按工程脚本运行或构建；缺少依赖目录和构建目录是预期过滤，不一定是文件丢失。HTML 或多文件站点按其资源关系运行。

## 失败排查【推荐规范】

部署失败先核对是否为创建者、任务是否成功、源码或构建结果是否可用。链接打不开时检查完整链接、服务是否可达及页面错误；图片失效时核对素材可达性和相对路径。下载失败先看权限和生成目录是否存在，再读取响应错误；不要连续重复部署来掩盖构建错误。
